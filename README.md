# 熟達証書シミュレーター

ブルーアーカイブの熟達証書ショップをシミュレーションするWebツールです。

## 機能

### 月間取得量計算
対象月・1日あたりの取得設定を入力すると、週ごとの取得量（上限込み）を計算します。

- 週リセット: 月曜日固定
- 週上限: 12,000（マンスリー +2,000 / ハーフマンスリー +1,000 で増加）
- 各週の理論値・取得量・損失を表形式で表示
- ウィークリーミッションが有効な場合、週ボーナス列を表示

対応している取得源:
| 設定項目 | 内容 |
|----------|------|
| 自動回復 | AP/日（デフォルト240） |
| カフェ | AP/日（上限740） |
| サークル入場 | +10/日 |
| 無料パッケージ | +10/日 |
| デイリーミッション | +150/日 |
| ウィークリーミッション | +200/週 |
| 2weekスタミナパッケージ | +150/日（14・28・42日） |
| アニバーサリーAPパッケージ | +160/日（7〜35日） |
| 石割 | ×120 AP/日 |
| 中級ドリンク | ×60 AP/日 |
| 初級ドリンク | ×30 AP/日 |

### ショップシミュレーター
所持熟達証書を入力して、購入する商品を選択・シミュレーションします。

- 残り証書・消費合計をリアルタイム表示
- カテゴリタブ・キャラ名検索でフィルタリング
- 在庫数まで購入可能（MAX一括購入ボタンあり）
- 商品ごとに「購入済み」「購入不可」フラグを設定可能
  - フラグを立てた商品はタブ切替・ページ更新時にリスト末尾へ移動
- 月間取得量計算の結果をそのままシミュレーターに引き継ぎ可能

## ダーク/ライトモード

ヘッダー右の ☀️/🌙 ボタンで切り替え。設定はブラウザに保存されます。

## 設定の保存

すべての入力設定・カート・フィルター状態はブラウザのローカルストレージに自動保存されます。ページを再読み込みしても状態が維持されます。

## 開発

```bash
# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```
